# Personal Portfolio Website

A personal portfolio website built using HTML, CSS, and JavaScript. This project showcases my profile, skills, projects, and contact information through a responsive website.

## About the Project

This portfolio website is designed to create an online professional presence and showcase my technical skills and projects.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Home section
- About section
- Skills and experience
- Services section
- Portfolio / Projects section
- Contact section
- Responsive design

## Project Structure

```text
MyPortfolio/
```

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_LINK
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
